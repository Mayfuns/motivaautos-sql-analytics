# SQL Analysis

This folder contains the complete PostgreSQL analysis for the MotivaAutos automotive analytics project.

## Main SQL file

[Open the complete SQL analysis](MotivaAutos%20SQL.sql)

## Analysis covered

The SQL file includes:

- Exploration of cars, customers and orders tables
- Distinct customer cities and car colours
- Counts of orders, customers, cars, cities and colours
- Customer and vehicle filtering with `WHERE`
- AND / OR conditions
- Sorting and limiting results
- `BETWEEN`, `IN` and `ILIKE` filtering
- Aliases and arithmetic calculations
- Revenue, average sales, maximum and minimum price calculations
- Customer order counts using joins
- Revenue and quantity sold by vehicle
- Customers spending above average
- Most expensive vehicle analysis
- Revenue by year
- Customer age segmentation
- Vehicle price segmentation
- Missing-value handling with `COALESCE`
- Data conversion and currency formatting using `CAST` and `TO_CHAR`
- Sales by car colour compared with average order value
- Total revenue and quantity sold
- Gold / Silver / Bronze customer loyalty tiers
- Monthly sales trends across years
- Most frequently purchased car colour
- Multi-table joins across cars, orders and customers
- Query-plan inspection using `EXPLAIN ANALYSE`

## SQL techniques demonstrated

- SELECT and DISTINCT
- WHERE, AND, OR
- ORDER BY and LIMIT
- BETWEEN, IN and ILIKE
- Aggregate functions
- JOIN and LEFT JOIN
- GROUP BY and HAVING
- Subqueries
- CASE expressions
- COALESCE
- CAST and TO_CHAR
- EXTRACT
- EXPLAIN ANALYSE

The analysis is structured around practical automotive sales and customer questions rather than isolated syntax exercises.
